# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, religion, or sexual identity and orientation.

## Expected behavior

- Be respectful and constructive.
- Give and accept technical feedback in good faith.
- Respect language, cultural and accessibility considerations.
- Do not publish private information about another person.
- Do not introduce content that is unsafe or inappropriate for children.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this code. Serious incidents should be reported privately using the process in `SECURITY.md` rather than through a public issue.

This code is adapted from the Contributor Covenant, version 2.1.
