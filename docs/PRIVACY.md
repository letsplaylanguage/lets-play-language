# Data and Privacy

## Prototype principle

Collect the minimum data necessary to prove that the app and dashboard communicate in real time.

## Allowed event data

- Random anonymous session identifier
- Event type
- Screen number
- Language code
- Timestamp generated by the database
- Non-identifying interaction metadata, such as whether an answer was correct

## Excluded data

- Names or email addresses
- Telephone numbers
- Exact age or date of birth
- Voice or microphone recordings
- Device advertising identifiers
- Exact location
- Free-text messages from children
- IP addresses stored by application code

## Retention

For the eligibility prototype, retain only the amount of event history required to demonstrate persistence and dashboard activity. A production deployment requires a formal retention policy and legal/privacy review appropriate to its audience and jurisdictions.
